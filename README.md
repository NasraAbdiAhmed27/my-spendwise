
# SpendWise – Personal Finance Tracker

## 1. Project Description

SpendWise is a responsive personal finance tracking web application designed to help users manage their money more effectively.

The application allows users to record income and expenses, monitor their financial balance, organize transactions into categories, and view their financial activities through a simple dashboard.

SpendWise uses browser Local Storage to save transaction information so that users can access their saved records when they return to the website using the same browser.

## 2. Project Objectives

- Help users track their income and expenses.
- Calculate total income, expenses and available balance.
- Organize expenses into different categories.
- Allow users to add and delete transactions.
- Provide a simple and user-friendly dashboard.
- Store transaction data using Local Storage.

## 8. Deployment Process Summary

The SpendWise project was deployed using Netlify.

Deployment steps:

1. Completed the HTML, CSS and JavaScript files.
2. Tested the application locally in a web browser.
3. Created a public GitHub repository.
4. Uploaded the complete project files to GitHub.
5. Connected the GitHub repository to Netlify.
6. Configured the deployment settings.
7. Published the website.
8. Tested the live website.
9. Updated the source code and verified automatic deployment.
